# Elabora releases

Public installers, updater metadata and release notes for the Elabora desktop app.

Download a published version from this repository's Releases page. Official releases contain Windows x64 and macOS Apple Silicon/Intel installers, updater metadata, bilingual release notes, source revision provenance and SHA-256 checksums.

The application source is maintained separately. The open core is at https://github.com/aureliendossantos/elabora-core and the product website is https://elabora.studio.

Release assets are uploaded to a draft first and published only after all supported platform builds finish. No credentials or application source belong in this repository.
